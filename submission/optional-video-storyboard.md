# 玩乎：可选演示视频分镜

建议成片：约120秒，横屏16:9，中文字幕。视频为选交材料；本文件是尚未拍摄的分镜，不代表已有公开视频。公网仍待部署验收，所有“公开链接”镜头须在验收后拍摄。

## 拍摄口径

- 主角是用户如何理解三门问题，界面实录优先；旁白解释画面正在发生的事。
- 使用真实AI生成并经过核对的作品时，标明“此前真实生成，经作者核对”。使用预置示例时如实标注。
- 模拟数字、挑战反馈、等待秒数、来源和活动记录全部保留实际值，不后期替换成预想结果。
- 可压缩等待时间，但必须显示“等待过程已剪短”或倍速标识；不能用剪辑暗示生成瞬间完成。
- 录制公开演示窗口，不录无关私人页面、后台凭据或系统通知。公开视频地址仅在确已发布后填入提交表单。

## 可选补拍：真实检索与生成

如评审更需要看API整合，可另录一段连续证据视频：从真实问题搜索、选择摘要、点击生成开始，保留等待秒数，直到结构化草稿或实际失败状态出现。主片可截取8–12秒并注明等待经过剪短，完整片段作为备用。

录制顺序：

1. 从题目起步提示选择适用问题，展示当前仅支持两类标准模型。
2. 发起真实知乎检索，选择实际返回的摘要，保留标题、作者和来源入口。
3. 点击生成，保留真实等待时间；不展示凭据或请求中的私人材料。
4. 生成成功后展示草稿标识，核对内容并修改一处观察提示。
5. 生成不支持或失败时如实保留结果；重新拍摄可以，但不能拼接为一次并未成功的请求。

- [ ] 字幕在手机上可读，重要控件不被字幕遮挡；声音清晰。
- [ ] 没有用户人数、学习增益、收入、获奖或上线状态的无依据陈述。
