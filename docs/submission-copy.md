# 玩乎 · 让知乎文章变成可互动的知识实验

## 表单字段建议

### 项目名称
玩乎 · 让知乎文章变成可互动的知识实验

### 选择主题
知识读场（学习工具与知识生产）

### 一句话介绍
玩乎是一款深度融入知乎的浏览器插件：作者选中文章中的一段文字，就能生成可操作的互动演示；读者打开文章后，演示会自动嵌在原文对应位置，边读边试、边试边懂。

### 作品链接
填写可访问的玩乎演示页或部署后的作品地址。线上作品地址为 https://wanhu.asia；插件安装页为 https://wanhu.asia/extension。评委可直接访问阅读页，也可下载开发者模式插件体验知乎内嵌流程。

### 产品说明书（可直接粘贴）

知乎擅长沉淀高质量的解释，却仍然以“阅读”为主：读者遇到抽象概念、复杂因果或反直觉结论时，往往只能继续滚动、搜索，或离开文章寻找另一个解释；创作者也很难在写作时验证读者是否真的理解。

玩乎把互动理解层放回知乎文章本身。安装浏览器插件后：

1. 创作者在知乎写作页选中一段内容，打开玩乎侧栏。
2. 玩乎读取选段和知乎来源，生成一个可操作的互动演示，例如注意力分配、概率直觉、梯度下降或文章论证探索。
3. 创作者把普通玩乎链接粘贴回知乎文章，原文无需改写，也不会自动发布。
4. 读者打开文章时，插件自动识别链接，并在对应段落下方展开互动卡片。读者可以直接操作、收起、稍后回到侧栏，或复制自己的理解结论。
5. 每个演示保留知乎原文、作者和来源链接，互动讲解明确标注为 AI 辅助内容，方便核对。

玩乎的关键不是把文章搬到另一个 AI 页面，而是在知乎原有的阅读关系中增加一个“可以试一试”的层：作者获得新的知识表达和思考工具，读者获得即时的理解反馈，知乎文章仍然是内容来源和传播载体。

当前作品支持文章/回答选段生成、知乎来源识别、互动实验、正文自动嵌入、本页演示管理、分享链接、学习结论复制和失败恢复。插件不读取 Cookie，不绕过知乎限制，不修改原文，普通链接在未安装插件的情况下仍可打开完整演示页。

### 演示建议

演示一篇包含抽象概念的知乎文章：

- 先展示作者选中段落并生成互动演示；
- 复制链接并粘贴到文章；
- 切换读者视角，展示演示自动出现在原文段落下方；
- 让评委操作一次，再展示“复制我的理解结论”和“稍后看”；
- 最后强调原文不变、来源可核对、知乎生态中的作者与读者都能受益。
