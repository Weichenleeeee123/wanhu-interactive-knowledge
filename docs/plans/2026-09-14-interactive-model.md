# 从问答题到可操作模型

用户已要求直接完善互动表达范围，本次按其授权执行，不另设设计确认。

## 设计

新增 interactive-model：1–3 个可调参数、1–3 个随时间变化的量、最多 100 个离散步骤。每个量有初始公式与更新公式；采用同一时刻的旧状态同步计算下一步。安全算术解释器只认识数字、标识符、四则运算、幂和少数数学函数，不执行模型提供的 JavaScript。

读者拖动滑杆、单步、播放、直接运行到终点；图表呈现轨迹，可回看任意一步、固定对照再改变参数。每条曲线单独选择，避免把不同单位混在一个纵轴。创作者可折叠调整默认值、公式、规则与假设。原文卡片外层样式不改。

生成器优先使用通用模型或现有专用实验，只有用户明确要求练习题才生成 article-exploration。保留历史题卡解码。材料不足以建立合理机制时给出具体限制；不得编造经验数据或强行量化情感。所有生成模型显示规则和假设，并核验一条逐字原文证据。教学参数与原文事实明确区分。
