# 知乎文章导入与原文互动阅读

用户希望将知乎已有文章直接带入作品，并加强对知乎社区内容的实际使用。

## 已核实能力

- 官方 0.5.3 Skill 的比赛知识列表/详情无需鉴权。真实列表返回 10 份知识内容；详情含作者与 content 正文。接口提供的内容不保证等于原站全文。
- 本机官方 CLI 0.6.0 的 `question answers` 明确只返回摘要；`me content` 正文接口仅可读取本人创作。尚未提供 OAuth 应用凭据，不将开发者账号数据暴露给所有访客。
- 两个普通知乎文章/回答 URL 的公开页面请求实测 403，不绕过访问限制。

## 完整交互

1. 素材页加入“导入知乎内容”，提供文章/回答链接输入和官方知识内容列表。
2. 知识列表来自真实接口；选择后预览作者、接口正文和字数，确认后追加到当前素材与引用，保留已有内容。
3. 普通链接通过官方搜索匹配同一内容 ID 的摘要。只标注实际取得的摘要；无匹配时保留链接并提示粘贴段落，不拿其他文章顶替。
4. 导入内容较长时让用户选择段落，生成材料仍限制 20,000 字符；不静默截取。
5. 通用文章生成原文互动阅读：2–4 个概念/情境选择，每个附可核对的原文短句和来源。服务器验证引句确实出现于输入材料；所有生成内容都以对作者表达的辅助理解呈现，不编造计算模型或将文章观点当成测量结论。
6. 保留现有两种数值实验；扩展作品 schema、编辑器、读者页、分享与备份，让新形态走同一完整产品流程。

## 工程与验证

- 固定官方请求域名和知识列表中的 ID；链接仅解析知乎文章/回答/问题的合法路径，不提供任意 URL 抓取代理。
- 超时、响应体上限、限流、短期缓存和请求合并；失败不循环重试、不发送密钥给内容 API。
- 同步 Next 与 Worker 接口。
- 测试精确链接匹配、伪造域名、坏 ID、异常响应、片段标识、追加保护、原文引句校验、新作品分享与编辑。
- 使用一份真实官方知识内容验证导入和生成；记录成功/失败的实际结果，保留所有文件，不部署。
