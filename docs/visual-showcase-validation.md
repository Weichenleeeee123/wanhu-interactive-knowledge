# 手作演示与通用视觉能力验收 · 2026-09-14

## 本轮交付

- 十篇真实知乎文章/回答与十个独立编写的 React/SVG 专用演示，不调用产品内置 LLM 制作。
- 插件识别文章/回答 ID 后自动嵌入，标明项目方预制，不冒充原作者提供。
- 专用交互：发送 TCP 报文、操作归并队列、时间衰减对照、笔记检索、合上材料转述、机会成本比较、咖啡制备、共同原因干预、叶绿体能量接力、C4 跨细胞运输。
- 普通生成流程另外增加 scene-animation 与 branching-path，保留安全公式模型。原始模型输出不能执行 HTML、SVG 源码或 JavaScript。
- 未改动的预制作品分享后仍使用专用界面；在工坊编辑底层作品后，转入通用结构渲染，避免专用程序无视用户修改。

## 边界

十篇手作演示的可玩性不计为实时 LLM 生成效果。当前模型仅能选择应用已支持的通用形式，不能临时编写这些专用组件。早先单独验证通用生成时，一次复杂 SVG 请求超时；简化后 scene-animation 与 branching-path 均返回有效作品。未用这些请求制作评审示例。

知乎可能随网络、登录状态或页面结构变化要求登录/验证。实测成功不意味着未来永远可访问。没有正文时不注入，保留网页体验入口。

本轮网页、专用分享渲染与生成能力随同一版本发布；提交、部署及线上验收记录见 [部署记录](deployment-2026-09-14.md)。插件内置的十份预制组件可直接在对应知乎文章中运行。来源与评审体验顺序详见 `submission/real-article-demos.md`。
