## 真实集成

- 官方 CLI 通过系统凭证库认证；项目未保存真实凭据。
- 应用 `/api/search` 返回 5 条真实知乎结果。
- 梯度下降：真实 `/api/generate` 返回 HTTP 200，有效 `gradient-descent` 作品，`origin=ai`。
- 三门问题：从 UI 搜索「三门问题 换门」，选择作者宫非的《有哪些有趣反直觉的数学题? - 知乎》摘要，真实生成《三门问题：为什么换门不是五五开？》，`origin=ai`。编辑器和阅读页保留同一作者、来源 ID 和带溯源参数的 URL。
- 对真实草稿核对并修改开场及观察提示后，生成分享快照。在独立页面打开，运行 1000 次模拟、回答 2/3、展开引用：作品继续可用，URL payload 未变，原文入口可见。
- 无关烹饪材料返回 HTTP 200、`unsupported=true` 且无作品，原因明确说明不能映射至当前两类实验。
- 上述阅读页面控制台无 error。已查看桌面、390px 手机首页与工坊布局，无横向溢出或阻断操作。

## 审阅与修复

后端经过独立规格审阅与代码质量复审；前端经过独立只读审阅与复审。没有遗留 Critical / Important 项。

- 引用跳转改为展开来源卡片，不再覆盖承载作品的 fragment。
- 生成开始时捕获编辑版本，旧响应处理结束后不会覆盖较新的编辑；回归测试等待明确终态提示再检查标题。
- 粘贴超过 20,000 字符时完整保留文本，显示限制并禁用生成，不再静默截断。
- 学习率按 0.01 统一校验和输入，题面与判分使用相同数值。
- 来源域名严格区分知乎及其子域名。
- 搜索整体 30 秒、生成整体 45 秒，限制请求与响应大小并取消超时/超大读取。
- Windows CLI 命令长度预先检查，过长材料明确拒绝；限流身份表有容量上限并回收过期记录。
