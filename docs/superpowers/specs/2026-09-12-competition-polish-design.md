# 知玩参赛打磨设计

用户已授权继续打磨至可提交。沿用已经批准的两类可信实验与统一创作器，不扩展为任意代码生成器。

## 本轮取舍

优先补足学习过程、演示表达和真实可达性。扩大实验数量会分散正确性验证；只调整视觉无法证明学习价值。本轮选择把现有两类实验做成完整的预测、操作、解释、挑战和个人记录流程，再准备可部署的作品和必交说明。

## 用户体验

- 阅读页在实验前允许锁定自己的预测，不提前判分；实验后的固定挑战记录验证结果。用真实操作状态展示个人探索记录，不冒充用户研究或学习效果统计。
- 梯度下降提供收敛、一步到达、震荡、发散的参数快捷入口，仍使用同一计算引擎。三门问题增加穷举解释，说明为什么初选错误时换门必胜。
- 创作器提供两个题材的材料起步建议，减少空白页负担。用户仍需明确选择材料并点击生成。生成等待显示实际经过时间，不显示虚假完成比例。
- 保留纸色、墨绿、橙色的知识实验笔记风格；主操作先于宣传文字，改善字号、手机触控与状态反馈。
- 生成提示强调标准模型、来源与补充解释的区别，禁止用无来源轶事填充文案；梯度下降默认非零初值，让实验可观察。

## 公开运行

复用既有已登记站点及 React 组件。准备 Cloudflare Worker 兼容构建；部署存储只保留缓存和配额，不持久保存用户原始材料。模型密钥仅进入运行时 Secret。保持本地 Next.js 流程和文件。

对公网部署增加并发安全的每日上游配额、客户端速率限制与知乎摘要缓存，避免公开演示无约束消耗额度。无服务配置时示例依旧可用，并明确说明状态。站点权限变更按工具要求，在可审阅版本就绪后取得必要的用户确认。

## 必交资料

官方手册 2026-09-09 版本已在浏览器核实：公网可操作 Demo 与产品计划书必交，代码仓库及视频选交。决赛 3 分钟演示加 2 分钟问答；AI 场景价值35%、创新25%、完成25%、体验8%、计划书与演示7%。用户已确认报名、身份材料、建队均完成。

产出计划书、表单文案、三分钟演示、评委问答和可复现源码包。保留开发日志和来源。现有公开演示及赛前公开发布的规则表述需区分：在正式提报前不把发布、报名和作品提交混为一谈。

## 验收

现有规则、分享、服务端测试继续通过；新增回归覆盖预测锁定、操作记录、挑战反馈及参数情景。实际检查手机与桌面，公开版本另行检验真实调用和无登录读者体验。不得写入真实密钥、伪造学习成效、声称已经获奖或已替用户正式提交。
