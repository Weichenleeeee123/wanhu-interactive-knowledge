# 玩乎 UI 视觉改造设计

## 目标
将现有页面统一为知乎蓝白的知识编辑台风格，提升首屏理解速度、创建流程清晰度与阅读体验。

## 视觉方向
暖白底、深墨蓝正文、知乎蓝行动色，薄荷青表示互动状态，橙黄用于少量提示。采用细边框、柔和阴影、16px 圆角和有节制的入场动效。

## 覆盖范围
全局 Header、首页 Hero/示例卡片、创建工作台工具栏与面板、阅读页卡片层级及移动端断点。保持现有功能和路由不变。

## 验收标准
核心 CTA 在首屏可见；创建页步骤与当前状态清晰；按钮、输入框、卡片在桌面和窄屏下层级一致；键盘 focus 可见；现有 typecheck/build 通过。
