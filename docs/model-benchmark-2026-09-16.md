# 生成服务恢复与模型选型（2026-09-16）

本次选用当前服务上的 `gemini-3-flash`，替换 `gpt-6-astra`。优先目标是让用户在现有等待时间内拿到可运行、可核对的演示。没有把“接口返回了文本”当作生成成功，也没有因为模型名字较新就直接上线。

## 用户遇到的故障

插件显示 `Unexpected token '<'`。同一 Elo 请求经公开域名返回 HTTP 504 HTML，经 VPS 本地应用返回 HTTP 504 JSON；应用约 45 秒的生成预算已耗尽。Cloudflare 的 HTML 错误页又被客户端当作 JSON 解析，覆盖了真正的超时原因。

此次保留 45 秒总预算、最多一次结构修复与原句/公式校验；插件和网页增加 HTML 网关错误处理，显示可读错误并保留材料。结构修复现在收到具体字段路径和上次输出，不再只有模糊的错误描述。生成提示还明确隔离专用实验规则，避免把梯度下降解释套到其他主题。

## 怎么测试

- 同一 VPS、同一 `api.openai-next.com` 账号和 Chat Completions 接口，调用项目真实 `generateLesson` 和 `createGenerationProvider`。
- 计时包含模型等待、返回全文、结构校验、必要的一次修复；不以首字时间作为生成用时。
- 三个相同任务：Elo 积分公式互动、渗透作用 SVG 分镜、机会成本分支选择。追加用户截图里的 Elo 均值/单局波动选段。
- 验证 JSON、类型结构、逐字引句、合法公式及默认参数运行，再人工核对概念、公式与操作说明。
- 前期筛选测试默认参数，以及关闭思考/JSON 模式的兼容性。随后对候选使用改进后的相同提示。不同轮次没有混成一个“公平胜率”数字。
- **这是小样本线路测试，不是模型能力排行榜。名称来自中转商模型列表，不能据此验证其实际路由或官方型号身份。** 列表中有名字也不等于账号实际可调用。

## 最终配置复测

Gemini 最后一轮使用与生产一致的普通非流式请求，不添加兼容性不明的 `thinking`、`enable_thinking` 或 JSON 模式参数：

| 任务 | 用时 | 模型调用次数 | 产物 |
| --- | ---: | ---: | --- |
| 用户截图中的 Elo 波动选段 | 37.6 秒 | 2 | SVG 分镜 |
| Elo 评分公式 | 16.4 秒 | 1 | 可计算互动模型 |
| 渗透作用 | 19.2 秒 | 1 | SVG 分镜 |
| 机会成本 | 24.2 秒 | 1 | 可比较分支 |

数值实验仍有教学简化，SVG 仍可能出现示意比例或措辞不够准确的问题。此次结果支持选择更可靠的生成线路，不构成每次都成功或内容无需人工审核的承诺。

插件更新为 **0.4.4**；公开版目录为 `dist/extension-public`，链接 `https://wanhu.asia`。已安装用户重新加载该目录并刷新知乎页面即可得到错误提示修复。模型切换由服务端生效。
