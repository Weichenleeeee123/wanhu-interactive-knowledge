## 浏览器插件形态（2026-09-13）

本项目现在包含 Chrome/Edge Manifest V3 本地扩展，目录为 `dist/extension`。它把知乎页面变成玩乎的入口：

- 读者在文章或回答中选取一段文字，打开右下角“玩乎”，确认发送内容后生成原文互动阅读；
- 生成结果可插入选中段落之后，作为当前浏览器的个人互动批注；原文 DOM 和写作编辑器正文不被改写；
- 创作者在写作编辑器中选段，演示卡片会放在编辑器外，可到工坊继续编辑并复制分享链接；
- 本页演示保存到扩展本机存储，按知乎页面隔离，刷新后可恢复；可载入作者主动分享的阅读链接；
- 插件只请求构建时指定的玩乎后端，不读取知乎账号 Cookie、Access Secret，也不自动发布内容。

### 本地安装

1. 保持本地服务运行：`npm run dev -- -p 3003`，或使用已构建服务监听 `3003`。
2. 运行 `npm run build:extension`。
3. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，开启“开发者模式”。
4. 选择“加载已解压的扩展程序”，选择 `dist/extension`。
5. 打开可访问的知乎文章、回答或写作页，刷新页面后选段体验。

公开知乎页面可能因登录状态、风控或页面类型返回 403；插件会在这种情况下不抓取不可见内容。当前可访问的 `https://www.zhihu.com/tardis/bd/ans/2508126669` 在 2026 年 9 月 13 日的本地烟测返回 200，并能识别正文结构；普通回答地址当日返回 403，不能据此绕过知乎限制。
