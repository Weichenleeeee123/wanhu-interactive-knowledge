# 玩乎：从能用到顺手

本轮沿用已确认的知乎插件 / 网页、创作者 / 读者流程与蓝白品牌，保持正文嵌入样式。用户已授权直接完善体验。

## 设计与实现范围

1. 空白工坊突出材料、问题、生成。备份、导入、副本放入“更多操作”；尚无作品时隐藏编辑历史、分享、预览占位工具栏。已有输入仍自动保存。
2. 表单清楚区分“准备材料”和“想讲清 / 弄懂什么”。辅助构思保持可选，不抢生成主操作。
3. 生成显示真实已等待秒数，提供停止等待。停止保留输入并忽略迟到结果；不伪造百分比或模型阶段。
4. 生成成功把视线带到作品。插件已有正文卡片时改为“查看正文中的演示”，并能回到选段继续；复制链接后的提示按角色区分。
5. 阅读页提供直接动手和立即追问，长说明不阻挡互动入口。分享面板按作者 / 读者展示下一步。
6. 核实并同步已有 OAuth 凭证到新 VPS；提供可发现的登录入口，授权后返回当前作品和角色，明确登录不等于云同步。

## 验证

覆盖停止后迟到结果、读者跳转、菜单可达性、阅读入口焦点、作者 / 读者分享、插件结果状态与 OAuth 返回地址校验；检查手机与桌面布局。保留原有作品、文件和来源署名。


## 实际结果

- OAuth 本地配置早已存在。本轮发现新 VPS 缺少 App ID / App Key，已同步三项 OAuth 配置并保留服务器环境备份。正式 `/api/auth/zhihu/start` 从 503 恢复到 307，知乎授权服务返回 302 到知乎登录页。没有代替用户完成授权，不把跳转成功宣称为真实账号回调成功。
- 新增导航登录入口；回调返回当前作品、角色和分享片段，返回地址只接受站内已知页面。会话为内存存储，服务重启后需要重新登录；作品仍保存在当前浏览器。
- 114 项单元测试、52 项网页测试、16 项插件测试通过，类型检查通过。新增覆盖停止等待、迟到结果丢弃、读者快捷入口、不同角色分享、登录返回地址。
- 第一轮回归发现菜单被吸顶栏遮住，修复层级与失焦关闭；旧测试等待已取消请求的成功响应，更新为验证请求取消及新编辑保留。随后完整 52 项网页测试通过。
- 已用浏览器查看窄屏工坊及真实 TCP 演示阅读页；工坊和阅读页的刘看山放在页尾，保留大尺寸，避免覆盖表单或动画。
- 原文自动嵌入的布局未改，十份手作演示未重新生成。
