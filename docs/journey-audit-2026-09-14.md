# 两端 × 两用户：提交前流程验收

验收日期：2026-09-14。范围：知乎插件 / 网页工坊 × 创作者 / 读者。此次按完整用户任务检查，不只验收十篇预制演示。

## 结论与边界

核心流程已经具备参赛提交条件。本轮补齐了真实链接导入、角色接续、外链识别、动画播放与更新引导。线上发布结果见本文末尾。预制十篇由开发者直接编写，不算实时模型生成。

OAuth 仍需赛事应用凭证完成真实联调；跨端通过分享快照接续为独立作品，不是云端共同编辑或实时版本同步。任意知乎链接不保证获得全文；插件读取用户可见选段，网页明确区分摘要与仅有链接。作者发布仍需把普通分享链接粘贴到知乎并自行发布，插件不代替作者提交。

## 本轮发现并修复

1. **SVG 播放崩溃（高）**：点击播放时首个 RAF 时间可能早于启动时刻，进度变成负数，读取不存在的 frame.title。夹紧时间增量与分镜下标；真实复现作品播放至第五幕，并新增强制早时间戳的浏览器回归测试。
2. **示例原文不能导入（中）**：导入解析只支持 Tardis jm/art，遗漏真实来源的 bd、zm。补全已知文章/回答链接，按文章身份匹配搜索结果；已核实的十篇可以预填标题作者，并直接打开预制演示。仍明确提示缺少全文，未把预制摘录冒充 API 全文。
3. **读者新建误入作者（中）**：新建链接缺少 mode；现在保留当前角色。导入时自动问题也按创作/阅读区分。
4. **知乎发布外链识别（高）**：知乎会使用 link.zhihu.com/?target=… 包裹分享链接。现在仅解析已知知乎包装，核验最终服务域名与作品格式，不跟随任意重定向。自动嵌入不再滚动打断阅读。
5. **正文与侧栏列表断开（中）**：已自动嵌入的作品之前尚未入本机存储，因此“本页演示”显示零。现在合并已嵌入与已保存作品并去重；切换到演示列表不再显示无关的长文选段错误。
6. **窄屏工具栏遮挡（中）**：大工具栏吸顶时遮住内容，半透明背景使文字叠加。窄屏改为随页面滚动，桌面使用不透明背景；收起窄屏刘看山气泡，保留角色本体。
7. **新演示入口难发现（中）**：首页两种主要入口之后直接提供十篇真实文章入口，替换仍强调“情境题”的旧流程文案。
8. **已安装旧插件与新服务不兼容（高，需用户更新）**：真实 Edge 中旧插件只接受 article-exploration / gradient-descent / monty-hall，收到新动画报 invalid discriminator。当前发布包升级 0.4.2，在侧栏显示版本，安装页解释覆盖原目录、重新加载、刷新知乎。网页更新不会自动替换已解压扩展的代码。

9. **快速选段后焦点转移（高）**：真实联网验收中，立即点击侧栏会清空 DOM 选区，延迟读取退化成整篇文章导致字数超限。改为 selectionchange 当时固定材料快照，延迟只用于合并状态更新；同时忽略侧栏输入框中的选区变化，避免编辑问题时丢失原文。快速清空选区及作者/读者侧栏编辑问题的回归测试均通过。
10. **公开分享封面地址（中）**：生产构建发现 metadataBase 未设置，会把分享图片指向 localhost。补充正式域名，避免分享预览失效。
